# Lastenheft Türsteuergerät (Beispiel)

- **LH-000**: Dieses Kapitel beschreibt die Anforderungen an das Türsteuergerät der Fahrertür.
- **LH-001**: Das Türsteuergerät muss die Fensterheber schnell ansteuern.
- **LH-002**: Die Versorgungsspannung muss 12 V betragen.
- **LH-003**: Im Fehlerfall sollen die Daten ggf. gespeichert werden.
- **LH-004**: Das Türsteuergerät muss Signale wie z. B. Türstatus, Fensterposition usw. auf dem CAN-Bus senden.
- **LH-005**: Das Türsteuergerät muss den Fehler speichern bzw. an das Gateway melden.
- **LH-006**: Das Türsteuergerät muss jederzeit über den CAN-Bus erreichbar sein.
- **LH-007**: Das Türsteuergerät muss den Fensterheber innerhalb von 200 ms ± 20 ms stoppen, wenn der Einklemmschutz auslöst.
- **LH-008**: Dies muss mit ausreichender Genauigkeit erfolgen.
- **LH-009**: Hinweis: Die Fensterposition wird vom Hall-Sensor im Fensterhebermotor geliefert.
- **LH-010**: The door control unit shall report the window position to the gateway every 100 ms ± 10 ms.
